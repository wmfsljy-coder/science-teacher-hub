# 우리 반 공유 뒷단

학생 화면의 **우리 반** 탭은 선생님 구글 시트에 성과를 쌓고 다시 읽어 옵니다. 자료는 선생님 계정의 시트에만 남습니다.

## 지금 상태: 켜져 있습니다

- 시트: **과학 수업** (선생님 드라이브. 주소는 공개 저장소에 적지 않습니다. 공유 설정은 반드시 **제한됨**으로 두세요.)
- 웹 앱 주소는 이미 모든 저장소의 `assets/share-config.js` 에 들어가 있습니다.

권한 승인까지 끝나 학생 올리기·우리 반 목록·활동 기록·선생님 화면이 모두 동작합니다.
교사 열쇠는 시트 **설정** 탭 B1 에 있습니다. 바꾸고 싶으면 B1 을 고치면 됩니다.

선생님 화면: https://wmfsljy-coder.github.io/science-teacher-hub/class/

### 다시 만들어야 할 때
1. 시트를 열고 메뉴 **우리 반 공유 → 준비하기 / 교사 열쇠 보기** 를 누릅니다.
   (권한을 물으면 허용. *확인되지 않았습니다* 가 뜨면 **고급 → 이동**. 내가 만든 내 스크립트입니다.)
2. 창에 뜬 **교사 열쇠**를 선생님 화면에 한 번 넣습니다.

## 선생님 화면 — 반별 활동
`science-teacher-hub/class/` 에 있습니다. 교사 열쇠를 넣으면
반 카드(학생 수·단원 수·마지막 활동), 단원 × 반 표, 최근 활동을 한눈에 봅니다.
반을 누르면 그 반만 봅니다. 학생이 쓴 글까지 보시려면 시트를 여세요.

## 시험 자료·지난 반 지우기
시트에서 그 반의 줄을 직접 지우는 것이 가장 쉽습니다(`share`·`활동` 두 탭).
한꺼번에 지울 때는 Claude 에게 "○○반 지워 줘" 라고 하면 됩니다. 뒷단의 `wipe` 요청은
교사 열쇠와 `confirm:'지움'` 이 있어야 하고 **POST 로만** 받습니다(링크를 눌러 지워지는 일이 없도록).
**되돌릴 수 없습니다.**

## 안전장치
- `반목록` 탭 A열에 적힌 반 코드만 받습니다. 기본값(1학년 1-1 ~ 1-7, 2학년 과목별 A·B반)은 준비하기가 만듭니다. 시트가 `1-1` 을 날짜(1월 1일)로 바꿔 버리면 스크립트가 알아서 `1-1` 글자로 되돌립니다. 반을 더하려면 A열에 코드를, B열에 이름을 적고, 같은 코드를 그 과목 저장소의 `assets/share-config.js` 의 `STH_CLASSES` 에도 넣으세요.
- 2026-10-03 시트를 **과학 수업**으로 옮겼습니다(옛 시트는 기록이 비어 있어 옮긴 것 없음, 웹 앱 주소도 새 주소).
- 학생 글이 `= + - @` 로 시작하면 앞에 `'` 를 붙여 **글자로만** 저장합니다. 그대로 두면 시트가 수식으로
  실행해 `=IMPORTXML` 같은 함수로 자료를 밖으로 보낼 수 있었습니다.
- 선생님 화면은 열쇠를 POST 로 보내 주소창·방문 기록에 남기지 않습니다.
- 반 전체가 한꺼번에 올리면 시트에 줄이 생깁니다. 30명 동시 시험에서 학생 화면이 스스로 잠깐 기다렸다
  다시 보내 **30명 모두** 올라갔습니다(가장 늦은 학생 약 30초).
- 웹 앱 주소는 페이지 소스에 보이므로 누구나 아무 반 코드로 올릴 수는 있습니다. 막으려면 `반목록` 탭에
  실제 반 코드를 적어 두세요(적힌 반만 받습니다).

## 시트에 쌓이는 것
- **share** 의 성과(JSON) 안 `_ev` — 수업 효과 기록(첫 추리 맞음/어긋남, 이야기 진행, 수준별 문제 한 번에 맞힌 수). 친구 목록에는 보내지 않고 선생님 화면의 **수업 효과** 표와 **모둠 편성 · 먼저 가 볼 학생**(students 동작, 반·단원 하나씩, 학생 글은 빼고 별명·첫 추리에서 고른 보기·진행·실험실 힌트 단계만)에 씁니다. 형식: `g:키=맞음1/0~고른 보기 번호 | e:이야기=푼/전체@막힌 장면 | q:한 번에/손댄 | h:푼 사례/손댄 사례/본 힌트 단계`.
- **share** — 학생 한 명의 한 단원에 한 줄. 다시 올리면 그 줄을 덮어씁니다. 지금 상태를 봅니다.
- **활동** — 올릴 때마다 한 줄씩 쌓기만 합니다. 덮어쓰지 않으므로 **반별 활동 기록**이 그대로 남습니다.
  (시각 · 반 · 별명 · 단원 · 올린 칸 수 · 처음/다시)
  반별로 보려면 이 탭에서 `반` 열을 기준으로 필터를 걸거나 피벗 테이블을 만드세요.
- 학생 화면의 **우리 반 활동 기록**은 `share` 탭을 반별로 모아 '어느 단원에 몇 명, 마지막이 언제'를 보여 줍니다.

## 운영
- 반 코드를 제한하려면 시트에 `반목록` 탭을 만들고 A열에 허용할 코드(예: `1-3`)를 적는다.
- 부적절한 글은 `share` 탭의 **숨김** 칸에 아무 글자나 적으면 학생 화면에서 사라진다. 줄을 지워도 된다.
- 학생에게는 **실명 대신 별명**을 쓰게 한다. 같은 반·같은 별명·같은 단원으로 다시 올리면 덮어쓴다.
- 개편하지 않은 단원(기후변화와 환경생태, 융합과학탐구, 과학의 역사와 문화, 과학탐구실험)은
  **정리하기에 쓴 답안**을 올립니다. 글 자체는 학생이 체크해야 올라가고, 체크하지 않으면 '작성함' 표시만 갑니다.
  '아직 헷갈리는 것' 칸은 다음 시간을 위한 혼자 메모라 아예 올라가지 않습니다.
- **생각 점검 표**: 시트 메뉴 **우리 반 공유 → 생각 점검 표 새로 만들기** 를 누르면 `생각 점검` 탭에
  단원 · 반 · 문장마다 처음 맞음 / 확신하고 틀림 / 이야기 뒤 맞음이 정리됩니다. 문장은 `precheck.gs`
  (`node _tools/make_precheck_gs.js` 가 만든 파일)에서 읽으므로, 문장을 고치면 이 파일도 다시 붙여 넣어야 합니다.
- **과목별 보기**: 시트를 열 때마다(또는 메뉴 **우리 반 공유 → 과목별 보기 새로 만들기**) 두 가지를 새로 씁니다.
  - `반별 명단` 탭 — 반 · 별명마다 한 줄: 과목, 올린 단원 수, 이야기를 다 마친 단원 수, 처음 올림, 마지막 활동, 올린 횟수. 필터가 걸려 있어 반·과목으로 바로 거를 수 있습니다.
  - `과목·통합과학1` 같은 과목 탭 — 위는 반 요약(반마다 학생 수, 단원마다 올린 학생 수와 다 마친 학생 수),
    아래는 반별 명단(학생 한 줄 × 단원 한 칸). 칸에는 `이야기 2/3 · 문제 4/6 · 생각 1→3/3`
    (이야기 마친 수/전체 · 수준별 문제 한 번에 맞힘/손댄 · 생각 점검 처음→이야기 뒤 맞힌 문장/두 번 답한 문장)이 들어가고,
    초록은 이야기를 다 마침, 노랑은 하는 중입니다. 기록이 생긴 과목만 탭이 생깁니다.
  단원 순서·이름·이야기 수는 `precheck.gs` 의 `UNIT_LIST` 에서 읽습니다(`node _tools/make_precheck_gs.js` 가 함께 만듭니다).
- 코드를 고친 뒤에는 Claude 가 `clasp push` + 같은 주소로 재배포합니다(주소는 그대로).
  직접 하시려면 **배포 → 배포 관리 → 수정(연필) → 새 버전** 입니다.
- 시트를 새로 만들어 처음부터 하시려면: 새 스프레드시트 → 확장 프로그램 → Apps Script →
  `Code.gs` 를 붙여 넣고 → 배포 → 새 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자) →
  나온 주소를 `assets/share-config.js` 에 넣습니다.
