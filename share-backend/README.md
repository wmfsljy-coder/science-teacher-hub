# 우리 반 공유 뒷단 켜기 (5분)

학생 화면의 **우리 반** 탭은 선생님 구글 시트에 성과를 쌓고 다시 읽어 옵니다. 자료는 선생님 계정의 시트에만 남습니다.

1. 구글 드라이브에서 새 **스프레드시트**를 만든다. (이름 예: 과학 도구 — 우리 반 공유)
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 들어 있는 코드를 지운 뒤 `Code.gs` 내용을 통째로 붙여 넣고 저장한다.
3. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포를 누르고 권한을 허용한다.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
5. 각 단원 저장소의 `assets/share-config.js` 에 그 주소를 넣는다. (Claude 에게 주소를 알려 주면 한꺼번에 넣어 푸시한다.)

## 시트에 쌓이는 것
- **share** — 학생 한 명의 한 단원에 한 줄. 다시 올리면 그 줄을 덮어씁니다. 지금 상태를 봅니다.
- **활동** — 올릴 때마다 한 줄씩 쌓기만 합니다. 덮어쓰지 않으므로 **반별 활동 기록**이 그대로 남습니다.
  (시각 · 반 · 별명 · 단원 · 올린 칸 수 · 처음/다시)
  반별로 보려면 이 탭에서 `반` 열을 기준으로 필터를 걸거나 피벗 테이블을 만드세요.
- 학생 화면의 **우리 반 활동 기록**은 `share` 탭을 반별로 모아 '어느 단원에 몇 명, 마지막이 언제'를 보여 줍니다.

## 운영
- 반 코드를 제한하려면 시트에 `반목록` 탭을 만들고 A열에 허용할 코드(예: `1-3`)를 적는다.
- 부적절한 글은 `share` 탭의 **숨김** 칸에 아무 글자나 적으면 학생 화면에서 사라진다. 줄을 지워도 된다.
- 학생에게는 **실명 대신 별명**을 쓰게 한다. 같은 반·같은 별명·같은 단원으로 다시 올리면 덮어쓴다.
- 개편하지 않은 단원(기후변화와 환경생태, 융합과학탐구, 과학의 역사와 문화, 과학탐구실험)은
  **정리하기에 쓴 답안**을 올립니다. 글 자체는 학생이 체크해야 올라가고, 체크하지 않으면 '작성함' 표시만 갑니다.
  '아직 헷갈리는 것' 칸은 다음 시간을 위한 혼자 메모라 아예 올라가지 않습니다.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해야 반영된다. 주소는 그대로다.
