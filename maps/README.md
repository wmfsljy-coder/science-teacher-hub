# 판 구조 지도 (plates.kml)

구글 내 지도(My Maps)에 가져와 쓰는 판 구조 지도입니다. 단원 쪽의 🗺 단추가 이 지도를 페이지 안에 띄웁니다.

## 들어 있는 것
- **판 경계 360줄**, 세 층으로 나뉩니다.
  - 발산형(빨강): 해령, 열곡대
  - 수렴형(파랑): 해구, 충돌대
  - 보존형(초록): 변환 단층
- **판 이름 20곳**: 유라시아판, 태평양판, 필리핀판, 인도-오스트레일리아판 등
- **이름 있는 지형 28곳**: 마리아나 해구(챌린저 해연)를 비롯한 해구 12곳, 해령·열곡대 7곳, 변환 단층·충돌대 5곳, 열점 4곳. 각 지형에는 어떤 판이 어떻게 만나는지 설명을 달았습니다.

## 출처와 손본 것
- **출처**: Bird, P. (2003) *An updated digital model of plate boundaries*, G³ 4(3), 1027 — PB2002. 변환본은 Hugo Ahlenius·Nordpil(github.com/fraxen/tectonicplates)이고, 이용 허락은 Open Data Commons Attribution License입니다.
- **판 묶기**: 교과서 지도에 맞춰 작은 판을 큰 판으로 묶었습니다. 예를 들어 아무르·양쯔·오키나와·순다는 유라시아판, 오호츠크는 북아메리카판, 인도·오스트레일리아는 인도-오스트레일리아판, 마리아나는 필리핀판으로 묶었습니다. 같은 묶음 안의 경계는 그리지 않았습니다.
- **해령 정리**: 해령 사이의 짧은 변환 단층(합쳐서 300 km 미만)은 해령으로 그렸습니다.
- **좌표**: 지형 위치는 어림값입니다.

## 다시 만들기
`_tools/make_plates_kml.py` 로 만듭니다(맨 위 주석에 쓰는 법). 판 묶기나 지형 목록을 바꾸면 다시 만든 뒤 내 지도에 다시 가져옵니다.

## 구글 내 지도에 올리기 (한 번만)
1. <https://www.google.com/mymaps> 에서 **새 지도 만들기**를 누릅니다.
2. 첫 레이어에서 **가져오기**를 누르고 이 `plates.kml` 을 올립니다.
3. 레이어마다 **스타일 → 라벨 설정 → 이름**을 고르면 판 이름이 지도에 글자로 보입니다.
4. **공유**에서 **링크가 있는 모든 사용자 → 보기 가능**으로 바꿉니다.
5. 주소창의 `mid=` 뒤 값(지도 ID)을 단원 쪽 `data-view="mymap:지도ID|위도,경도|줌"` 에 넣습니다.
