# 그림·영상·움짤 검토 (2026-11-04)

대상: 12과목 44단원의 최신 커밋. 대표 그림 43장, 캔버스 그림 410개를 직접 찍어서 봄.
기준: `VISUAL_GUIDE.md` 3단계. `mediacheck.py` 는 "문제 없음"(크기·용량·형식만 봄).

## 그대로 유지할 것
- 대표 그림: 43장 모두 같은 화풍, 900×900, 그림 안 글자 없음. 휴대폰에서도 선명함.
- 블록·디오라마 모형: 44단원 모두 있음.
- 영상·GIF 파일 0개. 움직임은 캔버스(K.animate)가 맡음 — 조작할 수 있고 용량이 없음.
- 저절로 움직이는 그림 123개 중 120개에 ⏸/▶ 단추가 있음.

## 높일 것 (효과 큰 순)
1. **휴대폰에서 그림 속 글자가 안 읽힘.** 글자의 89%가 가로 900 기준 13px 이하. 폭 375 화면에서 캔버스 폭이 301px이라(0.33배) 약 4px이 됨. QR 로 휴대폰 접속하는 수업의 핵심 문제.
   - `theme.css:209` 의 `main { padding: 30px 34px … }` 가 휴대폰용 `theme.css:202`(16px)를 덮어씀 → 고치면 337px 안팎(글자 약 4.9px). 그것만으로는 부족함.
   - `theme.css:217` `canvas { touch-action: pan-y }` 는 캔버스 위 두 손가락 확대를 막음 → `pan-y pinch-zoom`.
   - 캔버스마다 **🔍 크게 보기**(가로 화면 전체, 조작 유지)를 공통으로. 교실 화면에도 쓰임.
   - 장기: 휴대폰에서는 글이 많은 칸을 줄이고 값은 캔버스 밖 HTML 로. 글자 많은 장면부터.
2. **대표 그림 크게 보기 없음.** 넓은 화면에서는 2단(약 490px)으로만 보임. 누르면 확대. `<img>` 에 width·height 를 넣어 읽는 중 화면이 밀리지 않게.
3. **비율 안내.** 설명에 "실제 비율이 아님"을 밝힌 그림은 43장 중 3장. 지구·천문 16장에 안내가 없음.
4. **다시 볼 그림.** 지구과학Ⅱ 1-1 태풍: 눈이 좁고 높은 굴뚝, 구름이 바다까지 폭포처럼 내려옴(실제 눈은 지름 수십 km로 높이보다 넓음). 지구시스템Ⅰ 1-2: 바다 표면에 줄무늬(자기 줄무늬로 오해 소지). 다시 만들기는 이미지 생성 도구가 있는 세션에서. 통합과학1 1-2 대표 그림 없음(정책 거부, 우회하지 말 것).
5. **검사기 넓히기.** `mediacheck.py` 는 ⏸ 단추·반복 금지·움직임 줄이기를 그림별로 못 봄.
6. **작은 것.** ⏸ 없는 움직임 3곳(통합과학1 3-1 01 장면2, 3-3 01 장면4, 지구과학Ⅱ 3-2 03 장면5). 조작 전 빈 화면(탐구실험1 1-4 01 장면2, 통합과학2 2-1 02 장면3). 저절로 움직이지 않는 모형 18/44(단추를 눌러 움직이는 것 포함, 하나씩 판단 필요). 휴대폰에서 지구시스템Ⅱ 2-1 대조차 표가 상자 밖으로 나감.

## 영상
지금은 일괄 제작을 권하지 않음. 캔버스로 안 되는 실제 규모·시간 변화가 있는 단원에서 2~3개 시범 후 판단. 글자는 굽지 않음(가이드대로).

## 확인 못 한 것
실제 휴대폰, 두 손가락 확대의 실제 동작(CSS 규칙으로 판단), 움직임 줄이기 설정, 반복 금지 규칙, 바깥 자료 링크 344개. 대표 그림 정확성은 묶음 크기로 보고 4장만 확대함.
