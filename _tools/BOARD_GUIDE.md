# 칠판 강의 화면 · 개념정리 학습지 만들기 지침

본보기(정답 예시): `integrated-science-2/2-2/board-01.html`·`sheet-01.html`, `earth-system-2/2-2/board-01.html`·`sheet-01.html`.
엔진: `<저장소>/assets/board.js`·`board.css` (정본 integrated-science-2, `sync_assets.js` OPTIONAL). 엔진 사용법은 board.js 머리말.

## 만들 것 (소단원 = 이야기 한 편마다)
- `<단원>/board-0N.html` : 전자칠판용 강의 화면. N = 단원 안 이야기 번호(01, 02 …).
- `<단원>/sheet-0N.html` : A4 개념정리 학습지. 빈칸 번호·답이 board-0N 과 1:1.
- 단원 `index.html` 두 곳만 고친다.
  1. 그 이야기의 `<p class="teacher-note">교사용: …</p>` 줄 끝에 ` · 전자칠판용 <a href="board-0N.html">칠판 강의 화면</a> · 빈칸 번호가 같은 <a href="sheet-0N.html">개념정리 학습지</a>(<a href="sheet-0N.html?key=1">정답</a>)` (teacher-note 는 이야기마다 하나씩, 순서대로 있다).
  2. 맨 아래 **칠판모드 탭**(우리 반 다음)의 `#board-wrap` 카드에 그 소단원 줄(`.board-row`)을 이야기 순서대로 넣는다. 탭이 없으면 탭 단추(`<span class="num">` 번호는 이어서, `data-tab` 은 가장 큰 값 + 1)와 `<section class="tab-panel" data-panel="…" hidden>` 를 `</main>` 바로 앞에 만든다. 정리하기 탭에는 두지 않는다. 형식은 integrated-science-2/2-2/index.html 의 칠판모드 탭 그대로.
  3. 허브 첫 화면 위쪽 메뉴의 **📺 칠판모드** 쪽(site/app/board)은 단원 폴더의 `board-0N.html`·`sheet-0N.html` 을 빌드 때 읽어 과목별로 저절로 보여 준다(소단원 이름은 board 파일 `<title>` 의 ‘칠판 강의 · ○○ (…)’ 에서). 따로 고칠 것 없다.

## 내용 원칙
- **단원 화면의 이야기를 따른다.** 개념 순서·숫자·용어는 그 이야기의 장면 글, 미션 값, 결말, 과학자의 눈, LESSON.md(핵심 용어·첫 추리·오개념)에서 가져온다. 교과서마다 다른 값은 단원 화면 값으로 맞춘다. 확실하지 않은 수치는 쓰지 않는다.
- **구성(14~18장)**: 표지(dark cover, 부제는 1단계) → 도입(첫 추리 질문, 답 없음) → 오늘의 키워드(+ 빈칸 안내 카드) → 개념 장면들(파트 2~3개, data-part 로 묶음) → 확인(보기 고르기) → 오늘의 정리(4줄) → 문제로 확인하기(2문항) → 직접 해 보기·다음 시간(dark, 단원 화면 링크 index.html).
- **빈칸 12~16개.** 핵심 용어·핵심 값. 번호는 열리는 순서(장면 → 단계)대로 1부터. 같은 답을 두 번 빈칸으로 만들지 않는다. 오늘의 정리에는 새 빈칸을 두지 않는다. 빈칸 안내 카드의 예시는 `data-n` 없이 `<span class="blank on"><i class="bn">1</i>빈칸</span>`.
- **그림이 주인공.** 개념 장면마다 SVG 도식(단면·그래프·흐름·비교)을 하나 이상, 단계마다 한 부분씩 드러나게. 움직임은 `Board.on` 으로 한 번 진행하고 멈춘다(반복 금지, 움직임 줄이기면 끝 상태). 과장한 크기·거리는 그림 안에 `⚠ …` 로 밝힌다. 그림 안 오개념 금지(VISUAL_GUIDE 의 걸러 낸 예 참고).
- **대본(aside.script)**: 장면마다, 단계별 `<p data-at="k">`. 말하듯 쓰고 "빈칸 N번, ○○" 으로 번호를 짚는다. 첫 추리는 답을 주지 않는다는 지시를 넣는다.
- **말투**: 화면 문장은 짧은 명사형·'-다'. 대본은 선생님 말투('-요/-습니다'). 조사는 앞말에 붙이고 숫자와 단위는 띄운다(10 m, 0~50 ℃).
- 높은 대비: 글자는 26 px 이상(그림 안 눈금·주석은 18 px 이상), 연한 색 위 연한 글자 금지.

## 기술 규칙 (실제로 걸렸던 것)
- **SVG id 는 파일 전체에서 하나뿐이게.** 그라데이션·marker·clipPath id 가 다른 장면과 겹치면 숨은 장면의 정의를 가리켜 화살촉·채움이 사라진다. 장면 이름을 앞에 붙인다(`s4-grad`). 스크립트로 같은 그림을 여러 장면에 넣을 때는 꼬리표를 붙인다.
- 스크립트로 만든 SVG 의 `data-step` 도 엔진이 읽는다(첫 그리기 때 준비). 그림 스크립트는 board.js 다음 인라인 스크립트에.
- 화면 폭 1400 px(무대 1600 − 좌우 여백 100) 안에. 아래쪽 34 px 에는 `.note` 가 온다. 학생 복습판 조작 막대가 아래 가운데를 덮으므로 꼭 읽어야 할 글은 y 820 위에.
- 숫자 계산은 직접 검산한다(지수, 단위, 반올림).
- 엔진(board.js·board.css)은 고치지 않는다. 필요한 모양은 그 파일의 `<style>` 에.

## 확인 (끝내기 전에 모두)
1. `node _tools/boardcheck.js` → 「문제 없음」.
2. `python -X utf8 _tools/check_ids.py <저장소>/<단원>` → 문제 없음.
3. 허브 폴더를 로컬 서버로 띄우고(포트는 배정받은 것), 창 1440×900 에서 모든 장면을 `Board.go(i, 'end')` 로 열어 찍어 직접 본다: 글자 겹침·잘림·빈 그림·화살촉 없음. 첫 단계(0단계)도 몇 장 본다. 콘솔 오류 0.
4. 처음부터 끝까지 → 키로 넘겨 마지막 장면에 닿는지, ← 로 처음까지 돌아오는지.
5. `sheet-0N.html?key=1` 을 찍어 본다(학생 화면에는 교사용 정답 단추가 숨어 있어야 한다).
6. 단원 index.html 칠판모드 탭의 카드를 찍어 본다.
